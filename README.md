# منصة قصة العائلة | Qessa Family 🎬✨

الموقع التفاعلي الرسمي لقناة **قصة العائلة (@Qessa-family)** على يوتيوب: أروع حكايات وقصص الأطفال والرسوم المتحركة بالعربية، وعالم ألعاب أطفال متكامل ومحتوى عائلي هادف.

---

## 🚀 المميزات الرئيسية

1. **مزامنة فورية حقيقية مع قناة يوتيوب**:
   - التحقق من معرف القناة الحقيقي (`UChe5CsFfnSS0b6pWN1x3q0w`).
   - جلب أحدث القصص تلقائياً (مثل قصة **الثعلب مكرون وكذبة التفاحة** `opSJHrJX3mc`).
   - دعم YouTube Data API v3 خادمياً مع نظام فحص واستخراج احتياطي ذكي في حال عدم توفر المفتاح.
   - ذاكرة تخزين مؤقت Cache مدتها 10 دقائق مع آلية Stale-While-Revalidate ومكافحة السبام.
   - زر «تحديث القصص» للفحص عند الطلب.

2. **مشغل يوتيوب معزز للخصوصية واحتساب المشاهدات**:
   - استخدام مشغل `youtube-nocookie.com` بدون تشغيل تلقائي `autoplay=0`.
   - التشغيل بطلب صريح من الطفل/المستخدم.
   - نسبة عرض 16:9 وتوافق تام مع متطلبات المشاهدات المؤهلة.

3. **🎮 عالم ألعاب قصة العائلة (٦ ألعاب حقيقية مكتملة)**:
   - **لعبة الذاكرة 🧠**: مطابقة البطاقات مع ٣ مستويات وحساب الحركات.
   - **تركيب الصور 🧩**: بازل 3×3 و4×4 بمشاهد حكايات أصلية ومعاينة الصورة الأصلية.
   - **اكتشف الاختلافات 🔍**: ٣ مراحل تفاعلية مع تلميحات ذكية.
   - **كتاب التلوين 🎨**: تلوين رسومات أصلية مع إمكانية تحميل اللوحة محلياً كملف PNG إلى جهاز الطفل دون رفعها إلى الخادم.
   - **تحدي الحكايات 👑**: أسئلة قيم وأخلاق من قصص القناة مع وسام بطل الحكايات.
   - **مغامرة الغابة السحرية 🌳**: لعبة مغامرة 2D على Canvas مع دعم كامل للوحة المفاتيح وشاشات اللمس.

4. **ميزة اللعب أثناء الاستماع للقصة**:
   - إمكانية تشغيل لعبة خفيفة بجانب الفيديو على الكمبيوتر أو أسفله على الموبايل مع كتم صوت اللعبة تلقائياً أثناء تشغيل القصة.

5. **المفضلة والبحث المتقدم**:
   - حفظ المفضلة محلياً في المتصفح مع عداد حي وتصنيف خاص في التبويبات.
   - بحث عربي متقدم يتعامل مع الهمزات والتاء المربوطة والألف المقصورة وإزالة التشكيل.

6. **حماية وخصوصية الطفل (COPPA & GDPR-K)**:
   - عدم جمع أي بيانات شخصية أو حسابات للأطفال.
   - نافذة تفصيلية لسياسة الخصوصية موجهة لأولياء الأمور.

## 🛠️ كيفية تشغيل المشروع وتعيين مفتاح YouTube API

### تشغيل المشروع محلياً
```bash
npm install
npm run dev
```

### إعداد مفتاح YouTube Data API v3 (اختياري)
في حال رغبتك باستخدام حصتك الخاصة من YouTube Data API:
1. اذهب إلى [Google Cloud Console](https://console.cloud.google.com/).
2. فعّل خدمة **YouTube Data API v3**.
3. أنشئ **API Key** جديد.
4. أضف المفتاح إلى ملف `.env` (أو إعدادات Environment Variables في Vercel):
```env
YOUTUBE_API_KEY=your_api_key_here
```
> **ملاحظة**: الموقع يعمل بنجاح تام حتى بدون المفتاح بفضل نظام الاستخراج الخادمي الاحتياطي المدمج.
